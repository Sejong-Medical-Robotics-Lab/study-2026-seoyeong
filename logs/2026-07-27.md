## 오늘 배운 것 (3줄 요약)

- ROS2의 노드, 토픽, 메시지, 서비스의 역할과 각 요소가 서로 통신하는 구조를 배웠다.
- turtlesim을 이용해 토픽 발행, 서비스 호출, 파라미터 변경 등 ROS2의 기본 명령어를 실습했다.
- Python으로 발행·구독 노드를 직접 만들고, launch 파일과 tf2가 여러 노드 및 좌표계를 관리하는 방식을 배웠다.

## 직접 해본 것 / 성공한 것

- `ros2 node list`, `ros2 topic list`, `ros2 node info`, `ros2 topic echo`, `ros2 interface show`를 이용해 실행 중인 노드와 토픽의 정보를 확인했다.
- turtlesim에서 키보드로 거북이를 조종하고, 토픽과 서비스를 이용해 펜 색상 변경, 순간이동, 화면 초기화 등을 실행했다.
- 셸 스크립트를 작성하여 거북이가 지정된 좌표를 따라 사각형을 그리도록 만들었다.
- `my_first_pkg`라는 Python 기반 ROS2 패키지를 만들고, `greeter` 발행 노드와 `replier` 구독 노드를 작성했다.
- `greeter`가 `/greeting` 토픽으로 보낸 문자열을 `replier`가 수신하는 것을 확인했으며, `rqt_graph`를 통해 두 노드의 연결 구조를 확인했다.
- 기존 발행 노드를 응용하여 `driver.py`를 만들고, `Twist` 메시지를 `/turtle1/cmd_vel` 토픽으로 발행하여 teleop 없이 거북이가 원을 그리며 움직이도록 구현했다.
- `setup.py`에 실행 파일을 등록하고, `package.xml`에 필요한 의존성을 추가한 뒤 패키지를 다시 빌드했다.
- 코드 수정 후에는 `colcon build → source install/setup.bash → ros2 run` 순서로 실행해야 수정 사항이 반영된다는 것을 확인했다.
- launch 파일을 사용하면 여러 노드를 하나의 명령으로 실행하고 종료할 수 있다는 것을 배웠다.
- 파라미터를 변경하면 코드를 수정하거나 다시 빌드하지 않고도 실행 중인 노드의 설정을 바꿀 수 있다는 것을 확인했다.
- tf2가 로봇의 여러 좌표계 사이의 위치와 회전 관계를 부모-자식 구조로 관리한다는 것을 배웠다.

## 막힌 것 / 이해가 부족했던 것 (다음 Q&A 때 질문할 목록)

- `driver.py`를 작성하는 과정에서 Python 들여쓰기 오류가 발생했으나, 같은 코드 블록에 있는 문장들의 들여쓰기를 동일하게 수정하여 해결했다.
- `setup.py`와 `package.xml`이 패키지 실행 및 의존성 관리 과정에서 각각 어떤 역할을 하는지 더 정확히 이해할 필요가 있다.

## 한 줄 소감

처음에는 ROS2의 노드와 토픽이 추상적으로 느껴졌지만, 직접 발행·구독 노드를 만들고 거북이를 코드로 움직여 보면서 각 요소가 어떻게 연결되는지 이해할 수 있었다. 실행 파일과 노드 이름, 빌드 과정은 아직 익숙하지 않으므로 반복해서 연습해야겠다고 생각했다.
