## 3.4 자율학습미션 A
### 미션 ①
1. low state에 담긴 관절 데이터: 하체 12개(다리당 6개) + 허리 3개 + 양팔 14개(팔당 7개) = 총 29개/ 각 관절의 motor_state에는 대표적으로 다음 값이 포함된다.

## 5.2 자율학습미션 B
- 미션 ①  : Damp -> StandUp -> balancestand -> wave -> balancestand -> Damp
- 미션 ②  :
기립 전이 중 실패: except에서 오류를 출력하고 finally의 Damp()가 실행되어 안전한 감쇠 상태로 종료된다.
모션 중 Ctrl+C: except Exception에는 잡히지 않지만 finally는 실행되므로 Damp() 상태로 종료된다.
통신 끊김: finally에서 Damp()를 시도하지만 통신이 끊겼기 때문에 명령 전달이 보장되지 않아 로봇 상태를 확신할 수 없다.
-미션 ④  : 기존 02_wave_demo.py를 복사한 뒤 필요한 부분만 수정하여 진행하였다. g1edu/arm.py에 기존 오른팔 인사 동작을 좌우 대칭으로 변환한 왼팔 인사 동작을 추가하고, 복사한 실행 파일에서 오른팔 인사 후 왼팔 인사가 순서대로 실행되도록 코드를 수정하였다.       
1. `Damp()`
   - 대기: 1초
   - 기대 상태: 힘 빠짐
2. `StandUp()`
   - 대기: 20초
   - 기대 상태: 기립 상태(`balance_stand`)
   - 실패 시: `finally → Damp()`
3. `PlayAction("wave")`
   - 대기: 오른팔 동작 종료까지 + 0.5초
   - 기대 상태: 오른팔 인사 후 기본 자세
   - 실패 시: `finally → Damp()`
4. `PlayAction("left_wave")`
   - 대기: 왼팔 동작 종료까지 + 1초
   - 기대 상태: 왼팔 인사 후 기본 자세
   - 실패 시: `finally → Damp()`
5. `Damp()`
   - 대기: 1초
   - 기대 상태: 안전한 감쇠 상태
