# RM75 실기체 실습 학습일지

## 1. 실기체 데이터 확인

- 실기체에서 `/joint_states`를 통해 관절 상태를 확인하였다.
- 시뮬레이션(100Hz) 과 실기체(200Hz)에서 제공되는 데이터와 주기가 다를 수 있음을 확인하였다.
- 관절 속도와 상태 정보를 실제 ROS2 토픽을 통해 확인하면서 실기체의 데이터 흐름을 이해하였다.
- RM75 기본형에서는 '/joint_states'의 velocity와 effort가 비어 있고, 관절 속도는 별도의 '/rm_driver/udp_joint_speed' 토픽으로 확인한다.

## 2. 직접 교시 (Drag Teaching)

- 위치 제어 상태에서는 로봇이 현재 자세를 유지하려고 버티는 것을 확인하였다.
- 직접 교시 상태에서는 사람이 팔을 밀면 그 힘을 따라 부드럽게 움직였다.
- 이를 통해 **위치 제어와 컴플라이언스의 차이**를 실제 로봇에서 확인하였다.
- 관절7부분에 있는 초록색버튼을 누르면 직접교시를 할 수 있고 그 옆에 파란색 버튼을 누르면 직접교시했던 모션을 그대로 다시 하는걸 확인할 수 있었다.
- 이걸로 픽앤플레이스를 할 때 물병앞부분까지 가져가 말단에서 orientation을 측정하였다.

## 3. MoveJ / MoveJ_P / MoveL

- **MoveJ**: 관절 각도를 목표로 하여 관절 공간에서 이동
- **MoveJ_P**: 손끝의 위치·자세를 목표로 하지만 관절 공간에서 이동
- **MoveL**: 손끝이 작업 공간에서 직선 경로를 따라 이동

기본 모션 명령은 MoveIt2와 달리 별도의 Plan/Execute 과정 없이 명령과 함께 실행되므로, 실행 전에 경로와 주변 환경을 확인하는 것이 중요하다.

## 4. 그리퍼 제어

- 그리퍼의 열기와 닫기뿐만 아니라 물체를 잡을 때 필요한 파지력 제어를 확인하였다.
- 물체를 안정적으로 옮기기 위해서는 단순 위치 제어뿐 아니라 적절한 힘을 유지하는 것이 중요하다.
- 명령이 정상적으로 전달되었더라도 실제 물체가 잡혔는지는 별도로 확인해야 한다.

## 5. Pick-and-Place

물체에 접근하여 집고, 이동한 뒤 내려놓는 Pick-and-Place 동작을 수행하였다.

- 물체 근처로 이동
- 직선으로 접근
- 그리퍼로 물체 파지
- 물체 이동
- 목표 위치에서 내려놓기

## 막힌 것
- 생각보다 직접교시를 할 때 잘 안 돌아가서 당황했다. 각 관절이 어느방향으로 어떻게 움직이는지를 잘 알아야 좀더 잘 움직일 수 있을것 같다. 
- X,Y,Z방향이 각각 어딘지를 잘 인지하고 있어야 할 것 같다.
- 픽앤 플레이스로 물통을 집었을 때 집는 지점을 잘 설정해야 물통을 안 빠지고 원하는 위치까지 잘 움직일 수 있을 것 같다. 
- Pick-and-Place 수행 중 물병이 약 360° 회전하는 현상을 관찰하였다.
- MoveJ_P는 목표 End-Effector의 위치와 자세만 지정하고 실제 이동 경로는 관절 공간에서 결정된다. RM75는 7자유도 로봇이므로 동일한 말단 자세를 만족하는 여러 관절 조합이 존재할 수 있으며, 역기구학 해를 선택하는 과정에서 손목 관절이 크게 회전할 수 있음을 확인하였다.
