# 시연회 관람 기록 — 2026-07-24

## 플랫폼별 한 줄 관찰

- Go2: teleop으로 사족보행 로봇을 주행시키면서 LiDAR로 측정한 주변 환경이 rviz2에 실시간 표시되는 모습이 인상적이었다.
- G1: 행어에 로봇을 고정하고 비상정지 담당자를 배치한 상태에서 모션을 실행했으며, 수십 개 관절이 자유자재로 움직이는 모습이 멋있고 신기했다.
- FR3: rgb센서와 depth센서를 이용하여 물체를 감지하고 생수병을 잡는 모습이 인상깊었다.

## 오늘 배운 개념과의 연결

- Go2의 teleop 입력도 turtlesim의 `/turtle1/cmd_vel`처럼 속도 명령을 담은 토픽을 통해 전달된다고 이해했다.
- Go2의 LiDAR 데이터는 센서 노드가 메시지를  발행하고, rviz2가 해당 토픽을 구독하여 주변 환경을 시각화한다고 이해했다.
- G1의 각 관절 상태는 관절의 이름과 위치, 속도, 힘 등의 정보를 포함하는 메시지로 발행되며, 상태 모니터링 노드가 이를 구독하여 화면에 표시한다고 이해했다.
- G1은 자유도가 많아 여러 관절의 상태와 명령을 동시에 처리해야 하므로 turtlesim보다 훨씬 많은 노드와 토픽이 연결되어야 할 것 같다.
- FR3의 모션은 명령을 전달하는 노드, 경로를 생성하는 노드, 관절을 제어하는 노드, 실제 로봇과 통신하는 드라이버 노드가 서로 협력하여 실행된다고 이해했다.
