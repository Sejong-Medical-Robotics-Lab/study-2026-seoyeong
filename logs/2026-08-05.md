# 학습일지 2026-08-05 (Week 3 - RM75 Week)

## 오늘 배운 것
## 1. MoveIt2 동작 이해

RViz의 마커는 로봇의 목표 자세를 나타낸다.
Plan은 현재 자세에서 목표 자세까지의 궤적을 계산한다.
Execute를 눌러야 실제 관절이 움직인다.
## 2. 도달 가능 영역

마커를 작업 범위 밖으로 옮기면 로봇이 더 이상 따라오지 않았다. 이는 해당 위치와 자세를 만족하는 역기구학 해가 없기 때문이다.

## 3. 장애물 인식

박스 장애물은 화면에 배치하는 것만으로는 부족하며, Planning Scene에 Publish해야 MoveIt2가 장애물로 인식한다.

## 4. 관절 상태 확인

/joint_states에는 관절의 이름, 위치, 속도, effort가 포함된다. 각 값은 같은 인덱스끼리 대응하므로 반드시 name 배열과 함께 확인해야 한다.

## 5. 데이터 흐름 및 기록
/joint_states는 약 100 Hz로 발행되었다.
약 26초 동안 rosbag에 2617개의 메시지가 기록되어 발행 주기와 거의 일치했다.
rqt_graph에서 관절 상태는 move_group으로 들어가고, 계산된 궤적은 팔과 그리퍼 컨트롤러로 전달되는 것을 확인하였다.
## 6. effort 값과 시뮬레이션의 한계

demo 모드의 /joint_states에서 effort 값은 .nan으로 나타났다. 이는 현재 시뮬레이션 환경이 실제 관절 힘 정보를 제공하지 않기 때문이다.

RM75 기본형은 관절 토크 센서로 힘을 직접 측정하는 것이 아니라, 모터 전류를 이용해 힘을 간접적으로 추정한다. 따라서 실기체에서는 정지 상태에서도 자세 유지와 중력 보상 때문에 값이 나타날 수 있고, 외부 접촉이나 충돌이 발생하면 effort가 변할 것으로 예상된다.
